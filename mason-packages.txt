# astronvim_v5 需要的 mason 包清单

# 那 75 个是历次 :Mason 浏览时顺手装的，绝大多数语言根本用不到。

#   clangd        pkg:github/clangd/clangd           → clangd-linux-*.zip
#   pyright       pkg:npm/pyright                    → npm 包
#   rust-analyzer pkg:github/rust-lang/rust-analyzer → rust-analyzer-x86_64-unknown-linux-gnu.gz
#   gopls         pkg:golang/golang.org/x/tools/gopls
#   bash-language-server  pkg:npm/bash-language-server
#
# 加语言怎么办：见 editor/astronvim_v5/lang/ 下的语言包，别往这里堆。
